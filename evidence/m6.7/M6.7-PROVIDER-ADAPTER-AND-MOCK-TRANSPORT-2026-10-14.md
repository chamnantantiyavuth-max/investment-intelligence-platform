## 2. Public surface delivered

### `qad/m6/provider.py` — provider-neutral adapter contract

* `ProviderOutcomeKind` — bounded vocabulary: `RESULT`, `TRANSPORT_FAILURE`, `PIT_BLOCK`,
  `PROVIDER_CAPABILITY_INSUFFICIENT`, `PROOF_NOT_VERIFIED`.
* `TransportEvidence` — `transport_type`, `provider_surface`, `attempt_number`,
  `sent_source_ids`, `sent_blob_hashes`, `corpus_hash`, `sealed_bytes_verified`,
  `network_used`, `notes`.
* `ProviderOutcome` — `kind`, `provider_surface`, `attempt_number`, `result`, `failure_code`,
  `diagnostic`, `transport_evidence`, `telemetry`, `evidence_refs`; `is_success` property.
* `not_exposed_provider_telemetry()` — the truthful NOT_EXPOSED telemetry for a mock surface
  that genuinely exposes nothing (never a guessed or zero-as-unknown value).
* `DeepResearchProvider` Protocol — `capability()` + `execute(request, *, proof_resolver, attempt_number)`.
  **The adapter carries NO credential parameter** and imports no egress library.

### `qad/m6/mock_transport.py` — deterministic offline transport

* `MockTransportScript` — declarative per-attempt scripting (`TRANSPORT_FAILURE`), extraneous
  citations, withheld evidence, forced evidence references (adversarial fixtures), byte
  tampering and a "cannot enforce closed corpus" capability gap.
* `DeterministicMockTransport` — outcome generation only: it **never** classifies retry policy,
  **never** chooses an attempt number, **never** mints a proof and **never** touches the ledger.
* `MockExecutionEvidence` + `MockEvidenceStore` — independently checkable execution evidence.
  The store's write path requires a **module-private guard**, so an ordinary caller cannot
  inject a fabricated record; a record that was edited after the harness wrote it no longer
  matches its own recomputed reference.
* Evidence is minted for BOTH `ProofKind.CLOSED_CORPUS_ENFORCEMENT` and
  `ProofKind.REQUEST_ISOLATION`, digesting the FULL observed fact set (approved inventory,
  observed inventory, extraneous references, sealed-byte verification, isolation probe,
  foreign canary tokens, attempt number, producer).
* Deterministic re-execution of the same attempt re-mints the **identical** record
  (idempotent). A different record under an existing reference is refused.

### `qad/m6/mock_proof.py` — trusted mock resolver (explicit test-only injection)

* `MockProofResolver` — satisfies the M6.4 `DeepResearchProofResolver` protocol.
* It resolves the evidence reference to the harness's **recorded observations**, then:
  1. refuses an unknown reference (**a non-empty reference string is NOT proof**);
  2. refuses a record whose reference is not self-consistent with its own observations;
  3. refuses a record not produced by the mock harness;
  4. checks the exact six-field binding — `request_id`, `research_run_id`, `ledger_id`,
     `provider_surface`, `input_snapshot_hash`, `proof_kind` — against the context derived
     from the authoritative request;
  5. **re-checks the actual property** (closed-corpus inventory / request isolation) from the
     recorded observations — it never simply echoes provider-supplied identity and returns
     `verified=True`.
* Every failure returns `verified=False` with a bounded reason (fail closed).
* `MOCK_PROOF_RESOLVER_IS_TEST_ONLY = True`; absent explicit injection the M6.4
  **deny-all `DEFAULT_PROOF_RESOLVER` remains authoritative and SUCCESS fails closed**.
* This does NOT claim a real Gemini provider proof resolver — that is M6.8/M6.9.

### `qad/m6/orchestration.py` — additive entry point

* `run_provider_attempt(...)` — sequences the accepted M6.5 machinery:
  resolve/create the ONE logical run (idempotent), bind the request to the target run,
  validate the deterministic `AttemptPlan`, `provider.execute(...)`, map the bounded outcome
  onto the existing attempt-outcome vocabulary, then:
  * **SUCCESS**: `result.assert_proof_verified()` (FD #152 gate) → settle EVERY discovered
    source candidate through the accepted M6.6 bridge → `accept_success_result(...)`
    (which internally uses `finalize_success_attempt_atomic`);
  * **failure**: `record_failed_attempt(...)` → `decide_retry(...)`; if the retry budget is
    exhausted the accepted `terminalize_research_unavailable(...)` terminates the run.
* `ProviderExecutionOutcome` — `SUCCESS_FINALIZED`, `RETRY_SCHEDULED`, `RESEARCH_UNAVAILABLE`,
  `FAIL_CLOSED`.
* `ProviderExecutionResult` — durable read-back plus `result_sha256` / `result_artifact_ref`.
* **No second retry engine, no second source registry, no second atomic SUCCESS writer.**
  A fail-closed outcome is never retried merely because budget remains.

## 3. Proof boundary and truthfulness

* The transport's self-reported assertions are **not** evidence: the resolver reads the
  harness's recorded observations, re-derives the reference and re-checks the property.
* A fabricated/edited evidence record fails its own recomputation.
* Telemetry is always the truthful NOT_EXPOSED state (`reason = NOT_EXPOSED_BY_MOCK_PROVIDER`);
  false/missing/estimated telemetry is rejected by the accepted M6.3 validator.
* Provider-discovered references are **registered as candidates** and settled through the
  M6.6 bridge: with no trusted original-source verifier configured they are truthfully
  `DEFERRED / NO_TRUSTED_ORIGINAL_SOURCE_VERIFIER_CONFIGURED` — original verification and
  EV-01/EAR-01 evidence are **never fabricated**, and source-only admission is never
  presented as canonical evidence admission.

## 7. Interface note (NOT a contract change)

M6.4 derives the trusted proof context's `provider_surface` from the **request**, and M6.5
requires a SUCCESS result to carry the same surface as both its attestation and the validated
plan. A Mode A provider-fallback attempt can therefore only reach SUCCESS when the logical
request declares the surface that actually produces the result, while the ledger run keeps its
own configured surface for the deterministic INITIAL attempt. `test_14` is built that way and
reports the accepted fallback provenance (`PROVIDER_FALLBACK`, `provider_changed = True`).
Nothing in M6.4/M6.5 was modified; this is recorded for the Founder as an observed interface
constraint only — M6.7 fails closed rather than working around it.
