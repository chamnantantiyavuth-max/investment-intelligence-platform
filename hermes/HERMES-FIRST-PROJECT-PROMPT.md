- no application code has been created;
- no dependency has been installed;
- no migration or production integration exists;
- no final technology stack has been selected;
- the legacy repository has not been accessed;
- contradictions and unresolved questions are explicit;
- the proposed document plan preserves Theme Intelligence as shared core;
- Theme Quality, Candidate Quality, Entry Readiness, and Data Confidence remain separate;
- Experimental Themes cannot alter official strategy outputs;
- external content is treated as untrusted.

When the named plan is approved, draft only the approved Project Definition documents.

Treat the Constitution as a versioned working baseline, not an exhaustive final specification.
