## 5. Lessons

- **A NaN close is a fetch-layer event, not a market event — validate before you enrich.** The pipeline will happily render NaN into a "REAL EOD" report. The verify step (read `pipeline_result.json` for NaN before writing the SRL) is now mandatory in every weekly run. This run it caught the incident before enrichment and triggered the adapter fix.
- **The adapter's own cache fields are the cheapest blind-spot killer.** 50/200-day averages were present all along — 8 of this run's 9 open questions were answerable from cache fields (INTC 200-day position, FSLR base-break context, extension/compression vs MAs for every name). The 24 Aug SRL's "cannot assess" was a reading gap, not a data gap. **Every enrichment pass must dump the full cache field set once per run.**
- **Earnings-week detection is now a standard weekly check:** trailingEps change + calendar-adjacent date = earnings event (NVDA +21% refresh confirmed; CRWD print flagged; SMCI 2-week confirmation). The decoupling check (price ÷ P/E vs prior) remains the highest-value check; it now has a sibling: **a P/E that appears-but-is-absurd (CRWD 4,368) is a FIELD event — same rule as FSLR's stale EPS, opposite polarity.**
- **Stress-regime evidence is accumulating, not just one week:** week 1 risk-off (median −6.5%, 1/9 up) → week 2 stabilizing-and-diverging (median −0.4%, 4/9 up, leaders +13.8% vs laggard −4.6%). Q-Conditions clean both weeks. Breadth recovery with continued median-negative is a distinct regime signature worth watching — it is not "recovery" until the median turns positive.
- **Documented-but-unwired CLI flags rot silently.** `--refresh` was a no-op for weeks because the TTL-refresh path (the one the cron uses) never needed it. The docstring matched intent, not behavior. Wired it; docstring and behavior now agree.
- **Deferred data-quality fixes still need an owner and a re-review date** (unchanged from 24 Aug): CRWD's P/E has now been missing-or-absurd for 5 runs (None ×4 → 4,368). The FD #45 §8.1 deterministic sanity check remains the durable fix whenever Founder authorizes it.
