## 5. Lessons

- **Trailing-EPS drift is bidirectional AND non-monotonic — only a calendar-confirmed print makes a move evidence.** Full record: AMD 4.11 → 4.03 → **3.92** (kept falling); MDT 4.11 → 4.06 → **4.06** (retraced then stabilized); SMCI 3.41 → 3.50 → **3.26** (rose twice then retraced); NVDA 7.91 → 7.90 → 7.91 and AVGO 6.02 → 7.87 → 7.83 → 7.83 (held, both post-print). **The hold test is necessary but not sufficient — the print test is the primary discriminator.**
- **Treat yfinance trailing-EPS defects as a class, not a ticker.** CRWD (8 runs) and PANW (new) share one signature: a 2-decimal eps field → P/E in the hundreds/thousands. Any P/E-based screen must **fail closed** on this signature. FD #45 §8.1 is the fix; its evidence record is now 8 runs across 2 names.
- **A 2-name theme can carry a real sector signal — check pair medians before aggregating to the book median.** TH-030's pair moved +12.5% while the book median was +1.82%; the book median alone would have reported "mildly positive week" and hidden the only coherent sector event.
- **Report median + mean + spread together.** This week: median +1.82%, mean +3.56%, spread 21.2pts — the mean/median gap is the cheapest diagnostic for "a few big winners", a cheaper version of the top/bottom-identity rule the two prior logs adopted.
- **Read every large move as a macro narrative first, then attribute to the company.** One narrative (AI fear) plausibly explains opposite signs across sectors — security bid up, AI hardware soft. Company-level attribution without the macro read would have produced two contradictory "stories" for the same week.
- **Calendar-first grounding is cheap and it flipped a conclusion.** One `yfinance.calendar` call for all 9 tickers established that **no** name had a print in the window — converting PANW's 65% eps collapse from a possible fundamental event into a definite field defect.
- The 29 Aug rules held again: **verify coverage / as-of / NaN before enrichment** (clean) and **dump all cache fields once per run** (50d/200d MA context available for all 9).
