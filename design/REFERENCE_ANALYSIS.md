# Reference Analysis — Research Desk Direction

> **Phase H.1 — ui-dashboard-workflow v4.0.0 · 2026-08-04 · FD #51 direction A (Research Desk)**

## Primary reference: Financial Times / institutional equity research (print + web)

Research-note character: paper surface, serif display headlines, dense but airy ledgers, hairline separators, restrained color. Adopt the *character*, not any proprietary layout/branding/content (preservation rule).

| Dimension | Observation from reference | Classification |
|---|---|---|
| Page frame / max width | ~1100–1200px content column; generous margins | ADAPT — 1080px content, 220px rail |
| Navigation | Compact masthead; small-caps section links | ADOPT |
| Grid/alignment | Strict baseline; tables align to text grid | ADOPT |
| Spacing rhythm | 8px base; section gaps large (40px+), intra-section small | ADOPT |
| Type scale | Large serif display (36–48px), small-caps kickers (10–11px), 13–14px body | ADOPT |
| Density | Data-dense but not cramped; ledger row ~44px | ADAPT — 40px rows |
| Surface hierarchy | Paper white; subtle tinted zones for panels; NO per-card borders | ADOPT |
| Border strength | Masthead double rule; hairline row separators | ADOPT |
| Radius | Minimal (2–4px) | ADAPT — 4px |
| Shadow | None / ink only | ADOPT |
| Color roles | Black ink + one accent + semantic green/red muted | ADAPT — accent #1F4E79 (steel blue), positive sage, negative muted rose |
| Control sizes | Text links + compact buttons | ADAPT |
| Table density | Compact tables with header rules | ADOPT |
| Chart chrome | None in reference flow | ADOPT |
| Responsive | Columns collapse to stacked editorial flow | ADOPT |
| Interaction | Links over buttons; hover row tint | ADOPT |

## Secondary references

- **Typography hierarchy:** WSJ/Institutional Investor print (serif display + sans UI) — ADOPT for hierarchy model.
- **Tables/filters:** Bloomberg terminal tables (dense, mono numbers, hairline rows) — ADAPT for ledgers only; NOT the dark theme.

## Rejects

- Card-grid dashboard systems (generic SaaS) — REJECT (borderless policy).
- Marketing landing pages / hero banners with illustrations — REJECT.
- Dark themes — REJECT (direction A is light; direction B rejected by Founder).
